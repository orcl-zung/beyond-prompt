# Addy Agent Skills

Addy Osmani's agent skills organize software delivery into a legible lifecycle. The collection helps an agent move from an idea to a shipped change without skipping definition, planning, verification, or release discipline.

## The delivery loop

1. **Define** the problem, constraints, and success criteria.
2. **Plan** small tasks with explicit verification.
3. **Build** incrementally while keeping the system runnable.
4. **Verify and review** behavior, quality, and user experience.
5. **Ship** with release evidence and rollback awareness.
