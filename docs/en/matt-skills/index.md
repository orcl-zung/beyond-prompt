# Matt Skills

Matt Pocock's skill collection turns software-engineering judgment into explicit, reusable agent workflows. It focuses on the difficult parts around implementation: asking sharper questions, modeling a domain, choosing an execution path, diagnosing failures, and delivering work with evidence.

## What it covers

- **Clarify and model** before code makes assumptions expensive.
- **Prototype and test** to reduce uncertainty with working evidence.
- **Design deep modules** that keep interfaces small and responsibilities coherent.
- **Diagnose and review** through repeatable feedback loops.
- **Deliver and hand off** work in forms another person or agent can continue.
