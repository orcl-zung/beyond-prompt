# Frontend Skills

This section connects visual design, framework-aware implementation, and real-browser verification across Vue, React, and Next.js.

## Choose by task

- `frontend-design` for an intentional visual direction.
- `vue`, `vue-best-practices`, and `vue-testing-best-practices` for Vue 3 work.
- `vercel-react-best-practices` and `vercel-composition-patterns` for React performance and component APIs.
- `next-cache-components-adoption` and `next-cache-components-optimizer` for current Next.js 16.3+ App Router Cache Components work.
- `webapp-testing` for proving behavior in a real browser.

The detailed guide is maintained in [Simplified Chinese](/frontend-skills/).
