## 从 Prompt 走向系统

好的提示词只是起点。真正稳定的 AI 协作，来自清晰的技能边界、可观察的执行流程，以及经过设计的上下文。本手册持续整理这些实践，并将它们转化为可以直接使用的中文指南。

## 阅读路径

1. 从 [Matt Skills](/matt-skills/) 了解技能驱动的工程方法。
2. 在 [Claude Code](/claude-code/) 中建立日常 Agent 协作工作流。
3. 通过 [Context Engineering](/context-engineering/) 理解上下文如何影响结果。
4. 最后进入 [案例研究](/case-studies/)，观察方法如何落地。
